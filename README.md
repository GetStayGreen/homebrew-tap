# Stay Green Homebrew tap

```sh
brew install --cask getstaygreen/tap/stay-green
```

Stay Green is a small macOS menu-bar app that keeps Teams, Slack and Zoom from showing you
as Away while you read, think or take a call. It never moves your cursor. 14-day free trial,
no card or account. More at https://getstaygreen.com

The app updates itself (Sparkle), so `brew upgrade` skips it unless you pass `--greedy`.
